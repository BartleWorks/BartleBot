The first public beta of BartleBot.

Beta means it is ready to be used and is still being tested by the people using it. Expect
rough edges. When something goes wrong, please
[open an issue](https://github.com/The-World-Tree/BartleBot/issues) saying what you were
doing, and attach the session log from `%APPDATA%\Bartleby\BartleBot\logs`. A log never
names your wizards or your account.

Updates come through BartleBot itself: it checks each time it starts, and asks before
installing anything.
