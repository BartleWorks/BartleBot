# BartleBot

A Wizard101 bot for the repetitive parts of the game: farming dungeons, gathering, and the
fights in between.

[Download BartleBot](https://github.com/BartleWorks/BartleBot/releases/latest/download/BartleBot-win-Setup.exe){ .md-button .md-button--primary }

For 64-bit Windows 10 and 11, installed without an administrator. Windows will probably
warn you about it first: [Installing BartleBot](install.md) says what each warning means.

- **It runs dungeons for you, fights included.** Bots ship for dungeons in every world,
  and for gardening, crafting, housing gauntlets, raids and events. Each one is tested in
  game before it ships.
- **It plays your whole team.** Up to four of your own wizards run a bot together, each
  on its own account.
- **You can change any bot.** A bot is a graph of steps you can open, edit, and share with
  a friend as a file.
- **It keeps itself up to date.** New and fixed bots arrive with each update. BartleBot
  asks before installing one, and never while a bot is running.
- **It never plays PvP.** BartleBot will not start a bot that goes to a PvP zone, and
  stops if one is entered.

!!! note "BartleBot is in public beta"

    It is ready to use, and still being tested by the people using it. When something
    goes wrong, please [open an issue](https://github.com/BartleWorks/BartleBot/issues)
    saying what you were doing.
