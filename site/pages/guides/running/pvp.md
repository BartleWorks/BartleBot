# PvP

BartleBot is for PvE. It doesn't automate PvP, and there's no setting, option or file that turns that off. This page says which zones that covers, what happens if a run reaches one, and what stays allowed.

## Which zones are off limits

- **Beastmoon**, the whole world.
- **The PvP match arenas**, the zones where PvP matches are fought.

The arena lobbies, such as the one in Wizard City, are allowed. So is every zone with "Arena" in its name that isn't a PvP match, as in Darkmoor or Dragonspyre.

## A bot that names a PvP zone doesn't start

When a bot's steps name a PvP zone or Beastmoon, **Run bot** shows **Restricted Zone** and the run doesn't start. The message lists each step, the zone it names, and why it's off limits. There's no way past it. To run the bot, take those steps out of your own copy of it.

## A run that reaches PvP stops

If a player reaches a PvP zone during a run anyway, or is pulled into a PvP fight with players on both sides, BartleBot stops the bot at once and unhooks every game. The game windows stay open, and a **Restricted Zone** message says where the player went.

To carry on, move every player out of the zone yourself, then hook the games again with **Rehook All** in the **Players** tab and start the bot.

## PvE is allowed, raids included

Every PvE zone is allowed, whatever it holds: dungeons, bosses, Challenge Mode, gauntlets, raids, and the library's **Raid** bots. Challenge Mode fights use some of PvP's rules, such as match timers, and BartleBot fights them as the PvE fights they are.
